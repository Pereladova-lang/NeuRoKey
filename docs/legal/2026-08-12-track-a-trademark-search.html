4. Варианты действий

(для решения с юристом по товарным знакам, не окончательная рекомендация)

  1. Подать как есть, с юридической проверкой сходства — формальное заключение поверенного о различимости "NeuroKey" (образование, дети) и "NEUROKEY" (медицинское ПО для BCI).
  2. Комбинированный знак вместо словесного — конкретное написание "NeuRoKey" с нестандартным регистром + логотип обычно снижает риск отказа, но сужает объём защиты.
  3. Альтернативное название — опция, если прогноз юриста по п.1 плохой, не действие "по умолчанию".
  4. Подать в РФ первой (наименьший найденный риск здесь) с последующей заявкой по Мадридской системе.

5. Открытые вопросы для юриста по товарным знакам

  1. Официальный поиск по реестру Роспатента — есть ли непроиндексированные веб-поиском заявки на "NeuroKey"/"НейроКей".
  2. Проверить через WIPO Madrid Monitor, указана ли Россия как страна действия заявки NEUROKEY (сер. № 79345455).
  3. Профессиональная оценка сходства до степени смешения между двумя "NeuroKey" в классах 9/42.
  4. Оценить целесообразность регистрации комбинированного знака вместо словесного.
  5. Решить порядок подачи: РФ первой → Мадридская система, либо сразу международная заявка.
  6. Проверить актуальный статус заявки NEUROKEY (сер. № 79345455) — мог измениться с момента индексации.
